# 機能要件

機能ブロックごとに章立てする。各章で以下を必ず埋める:
- 何ができるか（画面仕様ではなく振る舞い・ビジネスルール中心）
- 判定ロジックの境界条件（閾値・優先順位・同点時の扱い）
- エラー時の挙動（オールオアナッシングか部分適用か）
- 権限・アクセス制御との関係

変更点は章内の該当箇所に `[継承]` `[変更]` `[追加]` `[削除]` タグを付けて明示する
（詳細は`README.md`参照）。以下、MasterMeister4の章構成を例として残してあるので、
必要な章だけ残し、不要な章は削除するか`[削除]`として理由とともに残す。
